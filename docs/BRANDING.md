# Tapp Find

Subtitle: **File & Content Search**.

Tapp Find retains the searching calico cat mascot and the planned expansion from metadata to file contents. Content search is not yet implemented.

The existing bundle identifier and local storage keys remain stable so the branding change preserves application identity and saved searches. Historical release notes retain the names used by their releases. The original image prompt retains MyFind. The Microsoft Store package identity and application ID also remain stable for updates.

The Tapp Find application icon is a calico cat looking through a magnifying glass. The source image is `assets/myfind-calico.png`, with transparent pixels outside the indigo tile. It was generated using the built-in image-generation tool, then converted by the Tauri icon generator to platform sizes. The original placeholder is archived as `assets/legacy-placeholder.svg`.

Regenerate native icons with `npm run tauri -- icon assets/myfind-calico.png`.

## Generation prompt

Use case: logo-brand. Asset type: finished square desktop application icon for MyFind, a file-search utility. Primary request: a charming curious CALICO CAT actively searching with a magnifying glass. Subject: expressive calico cat head and upper paws, unmistakable white fur with bold orange and charcoal patches, two alert ears, one bright eye enlarged by a large magnifying glass held in one paw. Friendly, clever, focused expression. Style: premium polished illustrated app icon, simplified sculpted shapes, restrained soft dimensional shading, crisp silhouette and strong readability at 32px. Composition: centered single cat and magnifying glass filling roughly 78% of a 1024x1024 canvas, ears and glass fully inside the icon. Background: indigo rounded-square app tile with generous rounded corners and transparent exterior; consistent with a refined productivity app. Use clear separations between white, orange, charcoal fur and indigo tile. No text, no letters, no watermark, no extra objects, no scenery, no border, no tiny decorative details. Actual transparent alpha outside the rounded-square tile.
